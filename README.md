# rijvearefin.github.io

Personal website of Rijve Arefin. Plain HTML/CSS/JS, no build step, free hosting on GitHub Pages.

## Go live at https://rijvearefin.github.io (free)

1. Sign in to GitHub as the account **rijvearefin** (create it at github.com/signup if needed; the username decides the URL).
2. Create a **public** repository named exactly `rijvearefin.github.io`.
3. Upload everything in this folder (`index.html`, `img/`, `favicon.svg`, `apple-touch-icon.png`, `icon-512.png`, `.nojekyll`).
4. Wait about a minute, then open https://rijvearefin.github.io

## Editing

- All text lives in `index.html`. Search for the section (`id="story"`, `id="press"`, etc.) and edit.
- Gallery photos are listed in the `photos` array near the bottom of `index.html`. Add a `.jpg` and `.webp` to `img/` and a line to the array.
- Press links: copy one `<a class="press">…</a>` block and change the link, outlet, date and headline.
